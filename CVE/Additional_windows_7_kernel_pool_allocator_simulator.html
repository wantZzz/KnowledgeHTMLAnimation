Windows 7 核心集區記憶體分配模擬器

本系統模擬核心驅動程式 (.sys) 呼叫 ExAllocatePoolWithTag 於分頁集區 (Paged Pool) 與非分頁集區 (NonPaged Pool) 的空間尋找、規劃與對齊行為。

x64 Architecture (1 Block = 16 Bytes) Page Size = 4096 Bytes

1. 核心申請參數設定 (ExAllocatePoolWithTag)

Bytes (8B - 12KB)
必須為 4 位 ASCII 字元，代表申請的核心模組。

2. 多步核心分配規劃演練

目前階段: 準備申請

請點擊「執行下一步驟」開始觀測核心對該對齊大小的搜尋、評估與排布流程。

1 邊界對齊與分界：計算 Payload 與對齊邊界。
2 集區決策：依據尺寸判斷使用小額或大額模式。
3 空間檢索：遍歷 Lookaside/ListHeads 或向 Mm 申領頁面。
4 規劃與寫入：寫入 POOL_HEADER、Tag，或寫入大額配置表。

3. 線性虛擬位址集區排布 (虛擬頁面剖析)

POOL_HEADER
已分配 Payload
空閒/可合併空間
NonPagedPool (線性起點: 0xFFFFFA8000000000) 實體鎖定, 常駐記憶體
PagedPool (線性起點: 0xFFFFF8a000000000) 分頁對應, 可置換至 pagefile.sys

請在上方排布點擊任何記憶體區塊以解析 POOL_HEADER
